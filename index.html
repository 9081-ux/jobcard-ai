How the routing works

  • Instant job processing — PREFER_ON_DEVICE. If Gemini Nano is on the device, the notes are processed there. If Nano is missing, the same call falls back to the cloud. If you are offline (real or simulated), it stays on-device — that is the whole point.
  • Weekly digest — ONLY_IN_CLOUD. A rollup needs the whole week at once; it runs in the cloud and honestly refuses when offline instead of faking it.
  • Every result is labeled. ON-DEVICE, CLOUD, or CLOUD · FALLBACK, with the measured milliseconds — never a hardcoded number.
  • Money is never invented. Invoice totals add up only the amounts written in the notes; the cloud model never gets to invent a price.
